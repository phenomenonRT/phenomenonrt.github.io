# Mimicry Generator — AmneziaWG × GTA V

Локальный генератор параметров AmneziaWG и шаблонов начальных UDP-пакетов
с формой сетевого трафика GTA V multiplayer. Проект помогает настроить
профиль AWG для эксперимента и посмотреть, какие поля будут заданы. Он
**не создаёт игровую сессию GTA V**, не является VPN-сервером или клиентом и
не гарантирует обход DPI или блокировок.

Генерация выполняется локально: ни браузер, ни CLI не отправляют seed,
параметры или ключи на внешний сервер.

Проект сделан по образцу `generatorM` (AmneziaWG × Minecraft): тот же
движок параметров, режимы, форматы вывода и проверки, но другие профили
мимикрии.

## Профили

| Профиль | Порт по умолчанию | Что имитирует |
|---|---|---|
| `fivem` | UDP 30120 | Начало сессии клиента FiveM: `getinfo xyz`, ENet `CONNECT`, первый reliable-пакет, keepalive `msgEnd` и `msgRoute` |
| `gtao` | UDP 6672 | Только размеры датаграмм GTA Online; структура пакетов закрыта и зашифрована |

### `fivem`

Последовательность повторяет клиент FiveM и сверена с его исходниками
([citizenfx/fivem](https://github.com/citizenfx/fivem), `NetLibrary.cpp`,
`NetLibraryImplV2.cpp`, `GameServerNet.ENet.cpp`):

| CPS | Содержимое шаблона | Источник в FiveM |
|---|---|---|
| `I1` | `FF FF FF FF` + `getinfo xyz` | `SendOutOfBand(.., "getinfo xyz")`: целое `-1` и текст; слово `xyz` у клиента постоянное |
| `I2` | ENet `CONNECT` (`0x82`): peerID `0x0FFF`, 2 канала, MTU **1300**, окно 65536, throttle 5000/2/2, случайный connectID, `data` = хеш токена | `enet_host_connect(host, addr, 2, HashString(token))`; `g_maxMtu = 1300`; без лимитов скорости |
| `I3` | ENet `SEND_RELIABLE` (`0x86`), канал 0, номер 1: `01 00 00 00` + `token=<uuid v4>&guid=<число>` | отправка при событии `CONNECT` |
| `I4` | ENet `SEND_UNSEQUENCED` (`0x49`), канал 1, 4 байта `63 9E 56 CA` (`msgEnd`) | keepalive каждые 100 мс |
| `I5` | ENet `SEND_UNRELIABLE` (`0x07`), канал 1: `5B 44 38 E9` (`msgRoute`) + netID + размер + случайный payload | пересылка `msgRoute` |

Токен в `I3` и поле `data` в `I2` согласованы: `data = joaat(token)`.
Функция `joaat` проверена на константе из исходников: `joaat("msgEnd") ==
0xCA569E63`. Заголовки ENet — публичные, big-endian; собственные поля FiveM —
little-endian. Размер `I5` растёт от `fast` к `stealth` и ограничен `MTU − 48`.

Чего здесь нет: перед UDP-подключением настоящий клиент делает HTTP-запрос
`initConnect`; ответов сервера (`VERIFY_CONNECT` и др.) нет, поэтому
`peerID` и номер сессии в `I3`–`I5` — случайные, а не выданные сервером;
игровые данные в реальности сжаты и упакованы, здесь payload случаен.
Команда `getstatus` не используется: клиент её не шлёт, а на сервере она по
умолчанию выключена (`sv_enableGetStatus = false`).

Для AWG 2.x значения H — эвристика, выбранная из команд ENet, которые
реально встречаются: `H1 = 130` (CONNECT), `H2 = 131` (VERIFY_CONNECT),
`H3 = 73` (SEND_UNSEQUENCED), `H4 = 134-137`. AWG использует H лишь как
32-битные числа, их никто не разбирает как ENet.

### `gtao`

Протокол GTA Online закрытый, поэтому `I1–I5` — это `<r N>` со случайным
содержимым и размерами из диапазонов режима (порт обычно UDP 6672 или
61455–61458). Структура пакетов **не воспроизводится**; профиль — слабая
имитация и оставлен для экспериментов с размерами. Для AWG 2.x используются
фиксированные различные значения `H1 = 200`, `H2 = 201`, `H3 = 202`,
`H4 = 203-210`.

## Что важно знать

- `Endpoint` — внешний UDP-адрес AWG-сервера. I-пакеты не открывают
  отдельное соединение с игровым сервером и ничего не меняют в маршруте.
- Эти пакеты уходят подряд перед каждым AWG-рукопожатием, без ответов
  сервера; AWG-сервер не отвечает как FiveM. Последовательность не является
  валидным диалогом с игровым сервером.
- После рукопожатия идёт AWG/WireGuard-трафик: S4, `ContentPaddingAddition`
  и `RandomTrailers` меняют его оформление, но не превращают в трафик GTA V.
- Если на том же IP и порту уже работает настоящий FiveM-сервер, UDP-порты
  конфликтуют: используйте отдельный IP, другой порт или NAT.
- Сигнатуры — снимок знаний о протоколах. После обновлений FiveM/GTA V или
  смены поведения DPI их стоит перегенерировать и проверить на своём
  провайдере.

## Что генерирует проект

- Web-интерфейс: клиентский `.conf`, серверный `.conf`, JSON endpoint типа
  `awg`, список параметров и разбор размеров пакетов.
- Python CLI: те же форматы и проверка ограничений через `--check`.
- Версии AWG 2.x и 3.1, режимы `fast`, `balanced`, `stealth`.
- Воспроизводимые параметры по seed. `HeaderProtectionKey` не выводится из
  seed и по умолчанию генерируется криптографически случайным. `<r N>` в
  CPS AWG заполняет случайными байтами при каждой отправке.

| Файл | Назначение |
|---|---|
| `index.html` | Локальная страница генератора |
| `styles.css` | Стили интерфейса |
| `app.js` | Генератор и web-интерфейс без сторонних библиотек |
| `mimicry.py` | Генератор CLI на Python |
| `test_mimicry.py` | Тесты и сравнение результатов JavaScript/Python |
| `verify/` | Проверка шаблонов `fivem` на настоящем ENet-сервере |

## Быстрый старт

### Web-интерфейс

Откройте `index.html` в современном браузере. Сборка и зависимости не нужны.
Выберите профиль, версию AWG и режим, задайте параметры и нажмите
«Сгенерировать». Результат — на вкладках «Параметры», «Клиент .conf»,
«Сервер .conf», «JSON» и «Пакеты».

### CLI

Нужен Python **3.10+**, внешние пакеты не требуются.

```sh
python mimicry.py                                   # клиентский .conf, профиль fivem
python mimicry.py --profile gtao --seed demo        # профиль GTA Online
python mimicry.py --seed demo --format json         # JSON для панели
python mimicry.py --format server --output server.conf
python mimicry.py --seed demo --check               # проверки; ненулевой код при ошибке
python mimicry.py --help
```

| Аргумент | Значения / назначение |
|---|---|
| `--profile` | `fivem` или `gtao`; по умолчанию `fivem` |
| `--awg` | `2` или `3` (AWG 3.1); по умолчанию `3` |
| `--mode` | `fast`, `balanced` или `stealth` |
| `--mtu` | от 576 до 1500; по умолчанию 1280 |
| `--ip` | IPv4 peer в JSON; по умолчанию `192.0.2.1` (адрес для документации) |
| `--port` | UDP-порт Endpoint, 1–65535; по умолчанию 30120 для `fivem`, 6672 для `gtao` |
| `--seed` | Seed для воспроизводимости; без него случайный |
| `--header-key` | `HeaderProtectionKey` AWG 3.x (base64 или hex) вместо случайного |
| `--format` | `client`, `server`, `json` или `params` |
| `--output` | Записать результат в файл |
| `--check` | Проверить ограничения и завершиться с ненулевым кодом при ошибке |

`192.0.2.1` — TEST-NET: не используйте его как реальный адрес сервера.

## Версии AWG и режимы

**AWG 2.x** — генерируются `Jc`, `Jmin`, `Jmax`, `S1–S4`, `H1–H4`, `I1–I5`.
**AWG 3.1** дополнительно: `HeaderProtectionKey`, `ContentPaddingAddition`,
`RandomTrailers`, `DisableCookies` и диапазоны таймеров; значения H1–H4
стандартные (`1`–`4`), ключ — 32 случайных байта в base64 и он должен быть
одинаков на клиенте и сервере (шаблоны из одной генерации это обеспечивают).

| Режим | `Jc` | `Jmin` | `Jmax` | AWG 3.x `ContentPaddingAddition` | `RandomTrailers` |
|---|---:|---:|---:|---:|---|
| `fast` | 2–4 | 32–64 | 160–400 | 12–64 | `off`; S1–S4 различаются |
| `balanced` | 4–7 | 48–96 | 300–800 | 16–128 | `on`; S1–S4 равны |
| `stealth` | 7–12 | 64–128 | 700–1200 | 32–256 | `on`; S1–S4 равны |

Режимы — пресеты, а не уровни гарантированной скрытности. Размеры payload
`I5` (fivem) и всех пакетов `gtao` растут от `fast` к `stealth` и
ограничены `MTU − 48`.

Рекомендуется AWG 3.1 и включённый `RandomTrailers`. MTU 1280 работает почти
везде; MTU 1352 даёт запас до 1492 (PPPoE) и для IPv6. `DisableCookies = on`
ослабляет защиту от handshake-флуда — используйте осознанно.

## Согласование и экспорт

| Параметр | Где требуется одинаковое значение |
|---|---|
| `S1–S4`, `H1–H4` | Клиент и сервер |
| `HeaderProtectionKey`, `RandomTrailers` | Клиент и сервер AWG 3.x |
| `Jc`, `Jmin`, `Jmax`, `I1–I5` | Клиент; на сервере не нужны |
| Таймеры и `PersistentKeepalive` | Клиент |

Экспортируемые шаблоны содержат плейсхолдеры ключей (`<PRIVATE_KEY>`,
`<SERVER_PUBLIC_KEY>`, `<PRESHARED_KEY>`, `<CLIENT_PUBLIC_KEY>`) и
`Endpoint = <SERVER_HOST>:<порт>` — замените их своими значениями и
проверьте адреса, маршрут, DNS и правила сервера. Клиентский шаблон —
full-tunnel (`AllowedIPs = 0.0.0.0/0, ::/0`). Серверный `.conf` — заготовка
без forwarding, NAT и firewall.

## Проверки и тесты

`--check` и вкладка «Параметры» проверяют внутренние ограничения: диапазоны,
MTU для junk и I-пакетов, непересечение H1–H4, правила S1–S4, для `fivem` —
`I1 = getinfo xyz` и MTU = 1300 в ENet CONNECT. Это не проверка импорта в
целевой сборке AWG и не тест соединения.

### Что проверялось на сторонних реализациях

- **AmneziaWG.** Конфиги разобраны официальными `amneziawg-tools`; шаблоны
  `I1–I5`, диапазоны `H`, `S`, ключ и таймеры прогнаны через код разбора из
  `amneziawg-go` (300 комбинаций, плюс контрольные заведомо неверные конфиги).
  Размеры I-пакетов, которые считает генератор, равны реально выпускаемым.
  Живое рукопожатие двух устройств AWG не проверялось.
- **ENet.** `verify/enet_check.py` собирает настоящий ENet 1.3.x-сервер и
  отправляет ему `I2–I5`: сервер принимает `CONNECT` и доставляет payload
  на каналы 0 и 1. Так проверена раскладка ENet; сходство с трафиком FiveM
  и работа DPI этим не проверяются.

```sh
python -B -m unittest discover -v
python -B -m py_compile mimicry.py test_mimicry.py
node --check app.js
```

Тесты сравнивают JS и Python по профилям, версиям, режимам, MTU, граничным
портам и адресам (нужен Node.js; без него этот тест пропускается).
Проверка ENet: см. `verify/enet_check.py` (нужны gcc и git, инструкция в начале файла).

## Ограничения

- Генератор меняет параметры и начальные сигнатуры, но не гарантирует
  скрытность. DPI/провайдер могут учитывать размеры, тайминги, ответы
  сервера, IP, порт и сам факт UDP-трафика либо блокировать endpoint.
- `fivem` повторяет начало сессии клиента по исходникам, но без HTTP
  `initConnect`, ответов сервера и настоящих игровых данных. Точный алгоритм
  `HashString` в поле `data` принят равным `joaat`; в версиях FiveM и ENet-форках
  детали могут отличаться.
- `gtao` повторяет лишь размеры и порт; реальный формат пакетов GTA Online
  закрыт.
- Профиль может устареть при обновлении игры, FiveM или DPI.
